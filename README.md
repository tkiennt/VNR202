## 🚀 TÍNH NĂNG CHÍNH CỦA HỆ THỐNG

1. **🗺️ Trục thời gian & Mốc son (1858 – 2026):** Bộ lọc 7 thời kỳ lịch sử, bảng 15 kỳ Đại hội Đảng toàn quốc và danh sách các đời Tổng Bí thư.
2. **📖 Học lý thuyết có cấu trúc:** 5 chương học (Nhập môn, Chương 1, Chương 2, Chương 3, Chương Mở rộng: ĐH XIII, XIV, NQ 57, NQ 68, PCTN) với bố cục trực quan, biểu bảng chi tiết, mẹo nhớ cốt lõi.
3. **⚖️ Bảng đối chiếu chuyên sâu:** 5 bảng phân tích trực quan các nội dung dễ nhầm lẫn (Cương lĩnh vs Luận cương, 3 Cao trào cách mạng, 3 Chiến lược chiến tranh của Mỹ, Cương lĩnh 1991 vs 2011, Bộ tứ trụ cột).
4. **🗂️ Flashcards phản xạ (35 thẻ):** Lật thẻ 3D trang nhã, phân loại theo chủ đề, ghi nhớ tiến độ vào `localStorage`.
5. **✍️ Luyện thi trắc nghiệm (100 câu):** 
   - *Chế độ Luyện tập:* Xem ngay đáp án đúng/sai, giải thích chi tiết và trích dẫn mục giáo trình.
   - *Chế độ Thi thử FPT:* Đề 40 câu ngẫu nhiên trong 30 phút có đếm ngược, chấm điểm thang 10 và xếp loại học lực.
   - *Chế độ Ôn câu làm sai:* Tự động lọc các câu bạn làm sai để làm lại cho đến khi thuộc.
   - *Đánh dấu sao (⭐):* Đánh dấu các câu hỏi khó để ôn cấp tốc trước giờ thi.
   - *Bảng Palette 1–100:* Nhảy nhanh đến bất kỳ câu hỏi nào.
6. **⚠️ Cảnh báo bẫy thi (8 câu):** Phân tích các câu hỏi gây tranh cãi hoặc có sơ suất trong ngân hàng đề gốc (C1-10, C1-20, C2-21, C2-23, C2-27, C2-35, C3-23, C3-32) kèm chiến lược chọn đáp án chính xác.
7. **🔍 Tìm kiếm tức thì (`Ctrl + K`):** Tra cứu nhanh full-text tất cả 100 câu hỏi, mốc năm, sự kiện và trích dẫn.

## 🛠️ HƯỚNG DẪN CÀI ĐẶT & CHẠY DỰ ÁN

### 1. Chạy trực tiếp trên máy tính (Không cần cài đặt)
Nhấp đúp chuột trực tiếp vào file `index.html` bằng bất kỳ trình duyệt nào (Chrome, Edge, Brave, Firefox, Safari...).

### 2. Chạy qua Local Web Server
```bash
# Khởi chạy server local
node server.js
# Truy cập tại: http://localhost:3000/
```

### 3. Deploy lên GitHub Pages
Dự án đã cấu hình sẵn GitHub Actions tại `.github/workflows/deploy.yml`. Khi push lên repository:
1. Vào repository trên GitHub: `Settings` → `Pages`.
2. Tại mục **Build and deployment** / **Source**: Chọn **GitHub Actions** (hoặc chọn branch `main` / `master` root `/`).
3. Website sẽ tự động deploy tại URL: `https://tkiennt.github.io/VNR202/`.
